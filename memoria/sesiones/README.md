# Sesiones

`/cerrar-sesion` crea aquí un archivo `AAAA-MM-DD.md` por día (si ya existe,
añade una sección nueva con la hora). Cada resumen incluye: qué se hizo, decisiones,
memoria actualizada y próximos pasos.

El hook de inicio de sesión lee el resumen más reciente para recordar dónde se quedó el usuario.
