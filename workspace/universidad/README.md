# Universidad

Una carpeta por materia en `kebab-case` (por ejemplo `calculo-ii/`), con esta estructura sugerida:

```
calculo-ii/
├── apuntes/
├── tareas/
└── examenes/
```

Para estudiar un tema de una materia usa `/estudiar <tema>`; el aprendizaje queda en
`memoria/aprendizajes/`. Si una materia tiene un trabajo grande, conviértelo en proyecto
con `/crear-proyecto`.
