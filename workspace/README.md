# Workspace

Aquí vive el trabajo del usuario. La memoria (`memoria/`) guarda **qué** está pasando;
el workspace guarda **los archivos** del trabajo.

| Carpeta | Uso |
|---|---|
| [proyectos/](proyectos/) | Una carpeta por proyecto, creada con `/crear-proyecto` |
| [universidad/](universidad/) | Una carpeta por materia: apuntes, tareas, exámenes |
| [investigaciones/](investigaciones/) | Informes generados por `/investigar` |
| [entregables/](entregables/) | Versiones finales listas para entregar |
| [inbox/](inbox/) | Material sin ordenar; usa `/organizar` para clasificarlo |
| [_archivo/](_archivo/) | Lo que ya no se usa (en lugar de borrar) |

Reglas detalladas: `.claude/rules/workspace.md`.
